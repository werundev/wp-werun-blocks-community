# Changelog

## 1.0.0

- First public release of werun.Blocks.Community, the free edition for the WordPress.org directory: the full block catalog (hero, section, CTA, media + text, features, logos, stats, tabs, table of contents, query, pricing, comparison, accordion, testimonials, timeline, video, carousel, jobs, form, notice), Saved styles, Integrations screen and WCAG 2.2 AA accessibility.
- No license, activation key or connection to any werun.dev server.
- Own prefixes (`werun-community/*`, `wrbc`, `WERUN_BLOCKS_COMMUNITY_*`, `Werun\BlocksCommunity`), so it can run next to werun.Blocks.
