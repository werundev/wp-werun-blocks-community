=== werun.Blocks.Community changelog ===

Every release, newest first. Each entry is also the description of its GitHub release, and readme.txt repeats the latest one under == Changelog ==.

= 1.2.0 =
* The Integrations screen follows werun.dev's newest look: a softer light ground, white cards with a fine border and a soft shadow, rounded corners, a light header with a pastel wash, and tags on a soft colour with a dot.
* Settings tabs look like the werun.dev customers area: the open one is a white tile with a dark mark. Switches have a round knob, and fields get a blue ring when you type in them.
* Search shows its counts on a blue tint and marks matching fields; sections with no match hide while you search.
* On a phone, the table of hosts this site may load stacks each row instead of scrolling sideways.
* The Help card has icon tiles and an arrow on the links that open another site. The footer says "Built to grow.", werun.dev's line.
* The plugin's page has a new Integrations screenshot.

= 1.1.0 =
* The Integrations screen follows werun.dev's new look: a light canvas, near-black text, square corners and the werun.dev mark in the header and footer.
* Colours now say what a control does: green for what is switched on and for saving, blue for what you can pick, red for what removes or fails.
* The screen's font (Hanken Grotesk, SIL OFL 1.1) is bundled with the plugin: the admin makes no remote requests.
* New werun.dev mark on the admin menu and on the blocks in the inserter. The plugin's page has a new icon, banner and Integrations screenshot.

= 1.0.1 =
* The werun.dev monogram images (admin menu and editor) no longer carry embedded file metadata.
* readme.txt now has screenshots: the blocks on a page, the editor's contrast check and the Integrations screen.

= 1.0.0 =
* First public release of werun.Blocks.Community, the free edition for the WordPress.org directory: the full block catalog (hero, section, CTA, media + text, features, logos, stats, tabs, table of contents, query, pricing, comparison, accordion, testimonials, timeline, video, carousel, jobs, form, notice), Saved styles, Integrations screen and WCAG 2.2 AA accessibility.
* Documentation (crm.werun.dev knowledge base) and support (GitHub issues) linked from the Integrations screen, the Plugins screen and readme.txt, with a contact link for custom work.
* No license, activation key or connection to any werun.dev server.
* Every external service documented in readme.txt (what it is, the hosts it uses, what data is sent and when, terms and privacy links). Maps, videos and third-party forms wait for the visitor's consent by default.
* Public REST routes (query results and gated downloads) only answer requests carrying input signed by the site, with a per-IP rate limit.
* Runs on PHP 7.4 or later and WordPress 6.6 or later.
* Own prefixes (werun-community/*, wrbc, WERUN_BLOCKS_COMMUNITY_*, Werun\BlocksCommunity), so it can run next to werun.Blocks.
