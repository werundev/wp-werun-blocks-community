=== werun.Blocks.Community changelog ===

Every release, newest first. Each entry is also the description of its GitHub release, and readme.txt repeats the latest one under == Changelog ==.

= 1.0.0 =
* First public release of werun.Blocks.Community, the free edition for the WordPress.org directory: the full block catalog (hero, section, CTA, media + text, features, logos, stats, tabs, table of contents, query, pricing, comparison, accordion, testimonials, timeline, video, carousel, jobs, form, notice), Saved styles, Integrations screen and WCAG 2.2 AA accessibility.
* Documentation (crm.werun.dev knowledge base) and support (GitHub issues) linked from the Integrations screen, the Plugins screen and readme.txt, with a contact link for custom work.
* No license, activation key or connection to any werun.dev server.
* Every external service documented in readme.txt (what it is, the hosts it uses, what data is sent and when, terms and privacy links). Maps, videos and third-party forms wait for the visitor's consent by default.
* Public REST routes (query results and gated downloads) only answer requests carrying input signed by the site, with a per-IP rate limit.
* Runs on PHP 7.4 or later and WordPress 6.6 or later.
* Own prefixes (werun-community/*, wrbc, WERUN_BLOCKS_COMMUNITY_*, Werun\BlocksCommunity), so it can run next to werun.Blocks.
